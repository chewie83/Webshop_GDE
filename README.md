# Webshop_GDE Projekt
1.	Előfeltételek:
•	Internetkapcsolat: Szükséges a Clerk (hitelesítés) és az adatbázis eléréséhez.
•	Node.js: Telepítve kell lennie a gépen.
2.	Indítási folyamat:
1.	Adatbázis és Backend:
o	Lépj be a backend mappába.
o	Futtasd az npm install parancsot.
o	Indítás: node server.js (vagy nodemon server.js).
2.	Frontend:
o	Lépj be a frontend mappába.
o	Futtasd az npm install parancsot.
o	Indítás: npm start.
